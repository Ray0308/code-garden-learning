# 第1ワール・カリキュラム

第1ワールは、プログラミング未経験者が1回5〜15分で進められる3章・12ステージとする。現在プレイ可能な0〜6階層は動作基準として維持し、`levels.js` の `worldOnePlan` に従って段階的に置き換える。

## 学習の進め方

各章は同じ四段階で支援を減らす。

1. `copy`: 完成例を見ながら全文を手入力する。
2. `fill`: 重要な命令や値だけを補う。
3. `debug`: 実行結果とエラーを手がかりに修正する。
4. `fromScratch`: 章で覚えた技を選び、ゼロから手入力する。

## 章構成

| 章 | テーマ | ステージ | 章末でできること |
| --- | --- | ---: | --- |
| 1 | 命令と実行順序 | 1-1〜1-4 | 移動、方向転換、操作の順序を自分で組み立てる |
| 2 | 文字列と `print()` | 2-1〜2-4 | 引用符とかっこを使って指定の文字を出力する |
| 3 | `for` と `range()` | 3-1〜3-4 | 重複する命令を繰り返しにまとめ、インデントを修正する |

## 実装順序

1. 1章の4ステージで、支援段階と手入力量をブラウザ検証する。
2. レベル一覧に章、支援段階、習得済みの技を表示する。
3. 2章と3章を追加し、章をまたいだ再利用課題を確認する。
4. 12ステージの回帰テストとスマートフォン実機検証を完了する。

条件分岐、入力と変数は第2ワール候補とし、第1ワールでは「命令を手入力し、エラーを直し、繰り返しで短く書く」ことの定着を優先する。
