# フォっくんの迷宮写経

プログラミング未経験者が、毎日5〜15分ほどダンジョンを攻略しながら手書きコードを身につける学習RPGです。Python・Java・PHP・JavaScriptの4言語に対応しています。

PC版Chromeとスマートフォン版Chromeを対象にしています。スマートフォンでは「コード」「ダンジョン」「ミッション」を切り替え、入力補助キーを使えます。進捗は匿名でブラウザ内だけに保存され、氏名や提出コードは収集・送信しません。

## 構成

- `core/language-registry.js`: 教材パックと実行エンジンを言語モードとして束ねる共通レジストリ
- `levels.js` / `courses/`: 共通の学習目標、言語別構文、所要時間、マップ、ミッション
- `engines/`: 言語ごとの構文解析と初心者向けエラー整形
- `docs/WORLD_1_CURRICULUM.md`: 第1ワール12ステージの実装計画
- `app.js`: 共通ゲームランタイム、ゲーム状態、画面制御
- `index.html` / `styles.css`: PC・スマートフォン共通UI
- `tests/`: 模範解答とレベル回帰テスト

教材データとゲーム本体を分け、将来のステージ追加と言語追加に対応しやすい構成です。言語モードは、同じIDを持つ教材パックと実行エンジンが両方登録されたときだけ画面へ表示されます。進捗も言語ごとに分離されます。

## 4言語共通基礎編

各言語モードは全48ステージです。前半24ステージでゲーム操作API、順次実行、出力、反復、入力、条件分岐を学び、後半24ステージで全言語に共通する基礎を各言語の文法で扱います。

- 変数、文字列・数値・真偽値、型変換
- 四則演算、剰余、比較演算子、論理演算子
- 条件分岐と繰り返しの組み合わせ
- リスト、辞書
- 教材内の仮想ファイルを使った `save()` / `load()`
- エラーの読み方と総合課題

`save()` / `load()` はブラウザ外へ送信せず、1回の実行中だけ保持する教材用APIです。本物のファイル操作は将来の言語別編で扱います。

## テスト

```powershell
node tests/levels.test.cjs
node tests/language-modes.test.cjs
node --check app.js
node --check levels.js
```

ブラウザ確認は、このフォルダで任意の静的HTTPサーバーを起動して `index.html` を開きます。

## GitHub接続のセットアップ（Windows）

`setup-github-access.bat` をダブルクリックすると、Git・GitHub CLIの検出、ログイン、認証設定、接続確認を半自動で行います。ログイン済みなら再認証は省略されます。

認証情報をCodexの隔離プロセスからも利用できるよう、初回ログイン時はGitHub CLIのファイル保存方式を使用します。共用PCでは実行しないでください。
